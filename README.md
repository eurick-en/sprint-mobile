# MarketLens Auto

Aplicação mobile desenvolvida em React Native + Expo para o desafio Ford de Inteligência Competitiva Automotiva.

## Tecnologias
- React Native
- Expo
- Expo Router
- Zustand
- TypeScript

## Funcionalidades
- Comparação inteligente de veículos
- Dashboard corporativo
- Favoritos
- Modal comparativo
- Navegação mobile
- Análise competitiva
