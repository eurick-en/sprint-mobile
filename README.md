# 🚗 MarketLens Auto

Aplicação mobile desenvolvida em React Native + Expo para o desafio de Inteligência Competitiva Automotiva da Ford.

O objetivo da solução é permitir a comparação estratégica entre veículos concorrentes, entregando análises inteligentes, dados técnicos organizados e uma experiência moderna para analistas automotivos.

---

# 📱 Tecnologias Utilizadas

- React Native
- Expo
- TypeScript
- Expo Router
- Zustand
- React Native Modal
- API/Data Integration
- Inteligência Artificial Simulada para análise competitiva

---

# 🧠 Inteligência Competitiva

O sistema utiliza uma camada de análise inteligente que compara atributos técnicos dos veículos para gerar insights automáticos, como:

- Melhor custo-benefício
- Maior potência
- Melhor eficiência operacional
- Perfil premium/esportivo
- Comparação estratégica entre concorrentes

A análise é gerada dinamicamente com base nos dados selecionados pelo usuário.

Entregar uma solução mobile moderna capaz de auxiliar na inteligência competitiva automotiva, permitindo análises rápidas, organizadas e estratégicas entre veículos concorrentes.
